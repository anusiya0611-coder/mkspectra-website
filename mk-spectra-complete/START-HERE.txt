MK SPECTRA - complete package
=============================

website/   -> your website (open contact.html with VS Code "Live Server")
backend/   -> Java (Spring Boot) backend that emails the contact form

BEFORE YOU START
1. Copy your existing site images (mk-dark.png, mk-light.png, wm-name-dark.png,
   wm-name-light.png, hero image, portfolio images ...) into  website/assets/
   (team photos are already in website/assets/team/).
2. Put your real phone numbers in website/contact.html (search for XXXXX).

RUN THE BACKEND (VS Code)
1. File > Open Folder > select the "backend" folder (pom.xml must be visible on top).
2. Wait until "Java: Ready" / importing finishes (first time 3-5 minutes, internet needed).
3. Open  backend/.vscode/launch.json  and put:
      MAIL_USERNAME = your Gmail (the one that has 2-Step Verification)
      MAIL_PASSWORD = the 16-letter Google App Password (no spaces)
      MAIL_TO       = mkspectra27@gmail.com  (where enquiries arrive)
   Save with Ctrl+S.
4. Press F5 (Run and Debug > "MK Spectra Backend").
   Terminal must show:  Started MkSpectraContactApplication

TEST
5. Open a NEW VS Code window with the "website" folder, right-click contact.html >
   "Open with Live Server", fill the form, click Send message.

NEVER upload/share backend/.vscode/launch.json or the target folder (it has your password).
When you deploy: change API_URL in website/contact.html to your live backend URL.
